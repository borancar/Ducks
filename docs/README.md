# Working notes

Two kinds of thing live here.

**[`notes/`](notes/)** is current and kept current: why the drawing port exists
and where it stands, what is still open and how far each one got, how to run a
session and read what it prints, and the conventions the work follows.

**[`sessions/`](sessions/)** is historical — a condensed log of each working
session, extracted from the conversation transcripts with
[`../export_sessions.py`](../export_sessions.py) and edited down. They are useful
for *how* a conclusion was reached, including the wrong turns, which is the part
a commit log cannot carry. They are not maintained: where a session log and a note
disagree, **the note wins**, and at least one such correction is called out
in place.

The README at the repository root documents the results themselves — the
unpacking, the emulation traps, the drawing path, the sound API.
